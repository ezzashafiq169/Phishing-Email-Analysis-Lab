# Phishing Email Analysis & Investigation Lab

## Project Overview
A hands-on cybersecurity project focused on investigating a simulated phishing email and identifying common phishing indicators using email security analysis techniques.

## Objectives
- Identify suspicious sender addresses and domains.
- Examine phishing URLs using VirusTotal.
- Investigate IP reputation and ownership.
- Understand SPF, DKIM, and DMARC authentication.
- Analyze email headers using MXToolbox.
- Document findings and recommend security actions.

## Tools Used
- VirusTotal
- MXToolbox Email Header Analyzer

## Investigation Summary
The simulated email impersonates Microsoft Account Security and uses urgency to convince the recipient to verify their account.

The investigation explored:
- Suspicious sender-domain patterns.
- URL reputation and vendor detection results.
- IP address ownership and shared infrastructure.
- SPF, DKIM, and DMARC authentication results.
- Email header fields and blacklist indicators.

## Key Learning Outcomes
- Recognizing phishing and domain impersonation.
- Understanding email authentication mechanisms.
- Interpreting threat-intelligence results.
- Documenting security findings.
